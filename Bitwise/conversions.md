decimal to base b
base b to decimal

1. decimal to base b:
eg: 17 to base 2

- keep dividing by base , take reminders and write in opposite.

for eg :  17/2  --> 10001   17/2 --> 8/2 --> 4/2 --> 2/2 --> 1 

eg: 17 to base 8

- keep dividing by base , take reminders and write in opposite.
for eg :  17/8  --> 21   17/8 --> 2/8 --> 0

2. base b to decimal:

eg: 10001 to decimal

- multiply each digit with base^position and add them up.

- 1*2^4 + 0*2^3 + 0*2^2 + 0*2^1 + 1*2^0 = 17

eg: 21 to decimal

- multiply each digit with base^position and add them up.
- 2*8^1 + 1*8^0 = 17

3. Base 2 to base 8:

base 2 to base 10 , then base 10 to base 8 easily .
