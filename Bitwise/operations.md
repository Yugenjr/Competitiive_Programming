and operator:

    both 1 - 1
    others - 0

or operator:

    any one is 1 - 1
    both 0 - 0

xor operator:

    both 0 - 0
    both 1 - 1
    others - 1
    xor of a with a - 0

not operator:

    0 - 1
    1 - 0

compliment :

    same as not operator

Number Systems:

Decimal - 0,1,2...9 (base 10)
Binary - 0,1 (base 2)
Octal - 0,1,2...7 (base 8)
Hexadecimal - 0,1,2...9,A,B,C,D,E,F (base 16)
