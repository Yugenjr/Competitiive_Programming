and operator:

    both 1 - 1
    others - 0

or operator:

    any one is 1 - 1
    both 0 - 0

xor operator:

    both 0 - 0
    both 1 - 1
    others - 1
    xor of a with a - 0

not operator:

    0 - 1
    1 - 0

compliment :

    same as not operator

Left Shift:

  for eg:  1010 base 2 ->  10100 

  so a<<1 = 2a
  so a<< b = a*2^b

Right Shift:

    for eg: 11001 >> 1 = > 1100 

    so a>>1 = a/2
    so a>>b = a/2^b

Number Systems:

Decimal - 0,1,2...9 (base 10)
Binary - 0,1 (base 2)
Octal - 0,1,2...7 (base 8)
Hexadecimal - 0,1,2...9,A,B,C,D,E,F (base 16)
